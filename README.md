## 📖 Descrição

Projeto desenvolvido na disciplina de **Programação Front-End** na **Unicesumar – Campus Londrina**.

O professor [Leonardo Rocha](https://github.com/LeonardossRocha) apresentou os conceitos fundamentais de frameworks front-end, utilizando o **Bootstrap** para estruturação visual, além da introdução ao **Git** e configuração do ambiente de desenvolvimento.

O objetivo principal do projeto é praticar:

- Estruturação HTML semântica
- Estilização com CSS
- Utilização de framework CSS (Bootstrap)
- Versionamento com Git
- Organização de projeto front-end

---

## 🚀 Funcionalidades

Atualmente o projeto possui:

✔️ Campo para inserção de Email  
✔️ Campo para inserção de Senha  
✔️ Checkbox "Lembrar-me" (ilustrativo)  
✔️ Botão FAQ (link demonstrativo)  
✔️ Layout responsivo com Bootstrap  

> ⚠️ Observação: O projeto está em fase inicial e possui caráter demonstrativo.
